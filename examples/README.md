# Examples

These files show what the system looks like on disk. They follow the real structure and wording of my vault, with the content rewritten:

- every job number, customer, part number, person and file path is **invented**;
- company-specific terms are replaced with plain ones;
- long files are trimmed.

| Path | What it is |
|---|---|
| [`CLAUDE.md`](CLAUDE.md) | An excerpt of my standing instructions to the agent |
| [`memory/MEMORY.md`](memory/MEMORY.md) | The index the agent loads at the start of every session, trimmed |
| [`memory/`](memory/) | Four complete lessons |
| [`skills/job-review/SKILL.md`](skills/job-review/SKILL.md) | One complete skill |
| [`vault/Daily Notes/2026-09-14.md`](vault/Daily%20Notes/2026-09-14.md) | A sample day |

| [`vault/Parts/240-71136.md`](vault/Parts/240-71136.md) | A sample part note |

The code blocks marked `dataview` are live queries. In Obsidian they render as tables and lists; on GitHub they show as the query text.
